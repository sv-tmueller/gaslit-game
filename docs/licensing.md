# Licensing

Gaslit splits its license in two, because the code and the game are not the
same thing.

The source code is MIT licensed. See [LICENSE](../LICENSE). You can read it,
fork it, modify it, and build your own game on top of it.

The art, audio, level design data, and the Gaslit name and logo are all
rights reserved. See [ASSETS-LICENSE](../ASSETS-LICENSE). Those are not
covered by the MIT license and cannot be copied or reused without
permission.

## FAQ

**Can I fork the engine and build my own game with it?**

Yes. The code is MIT licensed. Take it, learn from it, build something
different with it. Keep the copyright notice and the MIT licence text with
the code.

**Can I reskin Gaslit with my own art, audio, and levels?**

Yes. That's exactly the split this license is for: use the code, replace
the assets with your own original work, and ship your own game.

**Can I reupload Gaslit itself, as is, somewhere else?**

No. The game as a finished product depends on assets that are all rights
reserved. Reuploading the game verbatim, or a build using the original
assets, is not permitted.

**Is this legal advice?**

No. This is a licensing choice made for this project, not legal advice.
If you need legal guidance on how these licenses apply to your situation,
talk to a lawyer.
